# Marcin and Parker’s first workshop

The pilot is live at [OSE Tutor](https://ose-tutor.goodancestor.com/coach.html). It runs on the OSE Wikibot machine with a separate workshop database. Each builder and reviewer receives an individual invitation. An invitation link fills in the code. Select **Join workshop** or **Sign in**. Use the same invitation when returning on another device.

## As a builder

1. Choose **Wall Framing**, give the project a name and select **Create project**. Ask the tutor what a builder’s notes contribute to the housing library.
2. Choose **Build and inspect the frame**. Generate the reference wall and confirm the action. The OC16 example has four studs and three plates. Use the drawing and cut list to identify one of them. To compare two revisions, follow the spacing-change and drawing-repair lessons and regenerate.
3. From the saved project, select **Choose a contribution**. Pick a question you can address, claim it, and start the timer if you want your active time included. For fastening, identify the wall and the joint. Bring a dated drawing, marked-up build record, or other independent evidence. For a missing fact, write the specific question and who might answer it. You can also contribute a lumber quote, a width measurement, an adjoining-wall detail or a window-opening requirement.
4. Use **Submit for review** in the workshop task board. The reviewer can see the submitted finding, citations and available build comparison. Return to the task to read the decision and feedback. If asked for evidence, claim the returned task and submit a new round.

## As a reviewer

Open the [reviewer desk](https://ose-tutor.goodancestor.com/review.html) with your reviewer invitation. Select a submission. Read its scope, the cited revisions, the independent record and the affected schemas. If a project was built twice, examine the comparison. A submission made without a project or generated build can still raise a useful question.

Record what you accepted, which evidence you need, or why the question remains open. A contributor can see your reason. Acceptance records a reviewer’s decision about the submitted finding. Changing the wall instance, regenerating its files, and publishing an approved wiki draft are separate actions. The empty queue on first visit is expected until a builder submits work.

## What to bring back

Record which step first needed a person’s help, the source that settled the question, and whether another builder could follow the corrected instruction. For a transfer test, ask a second person to try the window-opening task. Review the revisioned wiki preview together before publishing it on the OSE wiki.

The included OSE model runs on the workshop host. Frontier checkout is disabled on this pilot. The [public walkthrough](https://opensourceecology.github.io/iconic-tutor/coach.html) and portable handoffs also work without a workshop account. [Operator guide](coach-workshop.md)
