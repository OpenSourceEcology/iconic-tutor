On the wiki, search for an existing page first; use Edit / Create, paste your draft, preview, add an edit summary and save only when ready. Existing page? Merge carefully, never replace it wholesale. On GitHub, review the prefilled issue before submitting. For long drafts, paste the downloaded text. Maintainers decide inclusion; a request does not add a selectable VCS icon.
